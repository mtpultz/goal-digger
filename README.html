Install Dependencies

Install VSCode

  • Download and install VSCode
  • Install the recommended extensions for the repository

Install Herd

  • Download and install Laravel Herd
  • Provides a development environment with Laravel, PHP, and Nginx

Install Postgres

  • Run brew install postgresql@17 to install Postgres
  • Run brew services start postgresql@17 to launch Postgres at login
  • Optionally, add psql to your PATH in .zshrc: 
export PATH="/opt/homebrew/opt/postgresql@17/bin:$PATH"

Install DBeaver

  • Download DBeaver
  • Connect to Postgres (default username: postgres or your macOS username)
  • Create a new database named goal_digger

Setup Application

  • Clone the repository into ~/Herd
  • Run composer install
  • Run npm install
  • Copy .env.example to .env and update DB_PASSWORD
  • Run php artisan key:generate
  • Run php artisan migrate:fresh
  • Run php artisan db:seed
  • Run composer run dev to start the application
  • Visit http://goal-digger.test
  • Run npm run setup:mcp to create the MCP config file

Note: Assumes you have a fine grained access token set in GITHUB_MCP_ACCESS_TOKEN with repository permissions of content, pull requests, and issues.

Using Access Tokens

  • Install an HTTP client (e.g., Postman, Insomnia)
  • Run php artisan passport:client --client
  • Set the default client name of Goal Digger
  • Copy the CLIENT_ID and CLIENT_SECRET into your HTTP client environment

Postman Setup

BASE_URL: http://goal-digger.test
CLIENT_ID: YOUR_CLIENT_ID
CLIENT_SECRET: YOUR_CLIENT_SECRET
CLIENT_USERNAME: YOUR_USERNAME
CLIENT_PASSWORD: YOUR_PASSWORD
ACCESS_TOKEN: SET_DYNAMICALLY_LEAVE_EMPTY

Create JSON headers preset:

Accept:application/json
Content-Type:application/json

Create a separate Auth preset header:

Client-Id:{{CLIENT_ID}}
Client-Secret:{{CLIENT_SECRET}}

Create a GET {{BASE_URL}}/oauth/token endpoint and add this test script:
